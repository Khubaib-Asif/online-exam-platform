# M3 — Question Bank — Future Scope

**Module:** M3 — Question Bank
**Status:** v1 boundary; no open v1 requirements
**Authoritative references:** `docs/architecture/HIGH_LEVEL_DESIGN.md` §§9, 12; `docs/architecture/LOW_LEVEL_DESIGN.md` §8; `docs/modules/MODULE_DECOMPOSITION.md` §3

This file records deliberately deferred capabilities without weakening immutable question-version guarantees.

## Deferred capabilities

- fill-in-the-blank questions;
- collaborative authoring and delegated question-bank ownership;
- adaptive question selection and item-response modelling;
- additional external import/export formats;
- automated translation and accessibility transformation pipelines; and
- advanced psychometric calibration and item-quality scoring.

## Boundary rule

A future question type or grading mode must define its authoring schema, student projection, answer-key secrecy, immutable-version behaviour, validation limits, and grading contract before implementation.
