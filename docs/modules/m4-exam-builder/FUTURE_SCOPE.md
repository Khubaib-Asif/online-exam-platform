**Module:** M4 — Exam Builder & Publication

**Authoritative references:** `docs/architecture/HIGH_LEVEL_DESIGN.md` §§9, 12, 14; `docs/architecture/LOW_LEVEL_DESIGN.md` §9; `docs/modules/MODULE_DECOMPOSITION.md` §3

This file records deliberately deferred authoring capabilities. It does not alter v1 timing, publication, or registration rules.

## Deferred capabilities

- institution/class/course audience assignment;
- reusable templates and cross-owner exam cloning;
- collaborative authoring and delegated publishing;
- runtime question pools and adaptive section paths;
- partial publication, rolling cohorts, and recurring schedules; and
- external LMS, calendar, or roster synchronisation.

## Boundary rule

Future authoring features must preserve immutable published revisions, server-authoritative timing, forward-only navigation, permanent question locking, and explicit M2 registration-policy ownership.
